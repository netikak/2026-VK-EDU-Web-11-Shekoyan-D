# AskPupkin · ДЗ4

Сайт вопросов и ответов с регистрацией, входом, профилем, публикацией вопросов и
ответов, оценками и выбором правильного ответа. На главной показываются новые
вопросы, на `/hot/` — лучшие по сумме оценок, на `/tag/<tag>/` — вопросы по тегу.

## Запуск через Docker

Из этой папки:

```sh
docker compose --env-file .env.docker up --build -d
docker compose --env-file .env.docker exec web python manage.py createsuperuser
docker compose --env-file .env.docker exec web python manage.py fill_db 10001
```

Сайт доступен на http://localhost:8001/, админка — на http://localhost:8001/admin/.
При запуске применяются миграции и собирается статика. nginx отдаёт `/static/`
и `/media/`. PostgreSQL и аватарки хранятся в отдельных именованных томах Compose.
Команда наполнения необязательна. Пустая база поддерживается.

## Локальный запуск

Нужны Python 3.12 и запущенный PostgreSQL. Создайте роль и базу под учётной записью
администратора PostgreSQL. Для имени роли и базы используйте значения `DB_USER` и
`DB_NAME` из `.env.local`. Для пароля роли используйте значение `DB_PASSWORD`.

```sh
createuser --createdb --pwprompt askpupkin_hw4
createdb --owner=askpupkin_hw4 askpupkin_hw4

python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Если локальные файлы окружения отсутствуют, скопируйте `.env.example` в
`.env.local` и `.env.docker`. Задайте секретный ключ и пароль БД.
Для Docker установите `DB_HOST=db`. Django Debug Toolbar подключается только
при `DEBUG=True`.

## Наполнение и проверки

```sh
python manage.py fill_db 2
python manage.py test
```

Команда `fill_db <ratio>` добавляет `ratio` пользователей и профилей,
`10 × ratio` вопросов, `100 × ratio` ответов, `ratio` тегов и
`200 × ratio` оценок. Повторный запуск добавляет новую порцию.
Минимум — `2`. При `ratio=1` единственный пользователь и 110 объектов допускают
только 110 уникальных оценок. Для объёма из задания используйте `10001`.
Тестовые пользователи создаются без паролей. Для работы в админке создайте суперпользователя.
Рейтинг вычисляется из оценок, поэтому добавление, редактирование и удаление
оценки в админке отражаются на сайте сразу.

## Как работает ДЗ4

- После регистрации пользователь входит в аккаунт и попадает на главную.
  После выхода публичная страница сохраняется, а страницы `/ask/` и `/profile/`
  снова запрашивают вход.
- В профиле можно изменить email и ник, загрузить или убрать аватар.
  Поддерживаются JPEG и PNG до 2 МБ.
- На странице вопроса ответы идут от старых к новым, по пять на страницу.
  После публикации открывается страница нового ответа с якорем на его карточку.
- Пользователь может сменить свою оценку на противоположную. В сумме
  учитывается только одна оценка каждого пользователя для данного объекта.
- Только автор вопроса может отметить один из его ответов правильным
  или снять отметку.
